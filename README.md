# synaptome
Collect, store, and share all the metrics from a research study as one portable object. Run the same stats and plots on demand.

synaptome is a lightweight Python library for managing research study outputs. Instead of scattering metrics across notebooks, CSVs, and one-off scripts, synaptome regroups everything from a single study into one object you can save, load, and hand to a collaborator. It comes with built-in statistical summaries and a library of the plots you end up making for every study anyway, so analysis and figures take seconds instead of a rewrite each time.
